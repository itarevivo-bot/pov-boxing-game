# Male reaction artwork

LEFT-hook and RIGHT-hook reaction PNGs remain in their separate directional folders.
Reaction animation lasts 525 ms. Five injury levels select existing reaction stages
1, 3, 5, 7 and 10 respectively. Impact travel is independent of anatomical damage.

Persistent idle no longer uses the historical unilateral idle files or cheek layers.
It selects one complete image for each exact state from `characters/idle/male-combined/`.
See that folder's README for the 36 required filenames and artwork requirements.
The old uploaded unilateral files are retained as references and are not used by
this renderer. Missing complete assets are reported; no faces are composited and
no cleaner or lower-level idle asset is substituted for the requested state.
